# CloudBot V8 整机原型

`CloudBot-V8.f3d` 是完整的 Fusion 装配。默认视图露出内部组件，打开左侧列表中 **91 Cloud diffuser envelope** 和 **92 Flowerpot reference** 的可见性即可查看外罩和花盆。模型以直径约 120 mm 的花盆作为比例参考，云罩是可手弯的金属丝骨架加半透明外罩。

| 打印件 | 装配位置与作用 |
| --- | --- |
| 01 一体底板 | 两端各一组滑轨和卡舌挡块，侧边集成灯带托板，中央挡板隔开水箱和摄像头。水箱下方预留直径 16 mm 的贯通口。 |
| 02 水箱 | 从有贯通口的一端滑入。自带卡舌和拉手，按卡舌可抽出，箱底直径 6 mm 的孔与底板口同轴。箱体几何内腔约 9.6 mL。 |
| 03 箱盖 | 翻过来盖在箱体上，内舌帮助定位，外侧有提手。当前盖是干装定位件，法兰与箱口之间留约 0.35 mm 给后续密封方案。 |
| 04 摄像头托盘 | 从底板另一端滑入。摄像头板靠在竖板上，扎带可从侧孔穿入，从底板上抽出托盘前先松开线缆。 |

两个滑入件按 R2 试样的 0.25 mm 卡舌侧向间隙建模。推到底后可轻拉检查是否锁住，拆时按压侧边卡舌并拉出。沿托盘侧孔固定板件前先看实物排线和插头位置。灯带托板的孔在灯带边上，扎带从托板底面穿回，不需要穿过其他板。

两根直径 3 mm、长约 145 mm 的不锈钢插杆使用底板上直径 3.5 mm 的通孔，孔距 64 mm。试装时可用杆用止动环在板下限位，先用配重检查拔脱和晃动。细铝丝云骨架用侧边四个孔绑在底板；遮罩保持可拆，并给镜头、卡舌和出雾口留开口。花盆、插杆、金属丝及电子元件是装配参考件。

打印时将 `CloudBot-V8-dry-plate.stl` 按毫米和 100% 比例导入，可一次放四件，或者选对应编号的单件 STL。切片预览时逐层看两条滑轨、贯通口和扎带孔。摄像头托盘两端的抬高侧翼可能需要可从外侧拆除的支撑。

本轮用于干式装配。雾化模块尚未确定，模型中的雾化片是尺寸占位，箱盖压紧和水路密封也尚未实测。定位盖和打印水箱先用配重验证卡扣和稳定性，等雾化器实物到手后再完成湿区接口和离开电子元件的单独试漏。
